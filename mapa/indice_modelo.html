Focos do 2º turno

Os 200 municípios onde a análise do 1º turno encontra mais votos recuperáveis para Lula, com a ação que os dados indicam em cada um e a margem de erro de cada estimativa. As taxas de transferência entre turnos vêm de inferência ecológica bayesiana sobre 2022, e os intervalos de 90%, de 2.000 simulações de Monte Carlo. São estimativas de um modelo, não previsões de resultado.

Código para incorporar na matéria

Cole este trecho no bloco de HTML da matéria. O iframe ajusta a própria altura ao conteúdo, no celular e no computador.

  • Se o editor do site não aceitar <script>, use só o <figure>: o mapa funciona com altura fixa de 1.100 pixels.
  • Para mais de um mapa na mesma página, troque o id="focos2t" nos dois lugares.
